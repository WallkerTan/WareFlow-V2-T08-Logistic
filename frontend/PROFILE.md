# Hồ sơ

/users/me GET/PUT quản lý tên, ảnh đại diện và profile; /users/me/password PUT đổi mật khẩu. Công ty dùng /companies/my-company GET và /companies/{id} PUT. Hồ sơ kho dùng /warehouses/{id}/profile PUT. Upload ảnh qua /upload/image rồi lưu secureUrl vào API hồ sơ. Chi tiết tại [README](README.md).
