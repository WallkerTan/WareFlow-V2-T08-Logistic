# Giao diện

Các màn hình hoạt động nằm trong src/page/live. Resource, Editor và API hooks dùng chung cho tải dữ liệu, phân trang, upload và xử lý lỗi. Menu theo quyền tại src/layout/navigation.ts, route tại src/routers/routers.tsx. Không còn kho dữ liệu mẫu hoặc cập nhật nghiệp vụ giả trong trình duyệt. Xem [README](README.md).
